# Contexto e descritores de anexos

A imagem integral recebida para R-media-07 contém uma mensagem histórica. O inventário a classifica como original restrito, conforme as regras de governança do projeto.

O recorte técnico aprovado está em [Descritores de anexos](../publicacao/04-descritores-anexos.png). Ele preserva aliases, tipo MIME, tamanho dos arquivos, limites de leitura e indicação de consulta opcional, sem publicar o histórico. A unidade foi reprovada por outros requisitos; a figura demonstra os descritores disponíveis, sem apresentar o caso como tarefa aprovada.
